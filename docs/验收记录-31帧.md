# 31帧变阻器已接入

版本：dsh-boss-slider 0.2.0；验收日期：2026-11-16。

## 使用

先刷新当前DSH网页一次，加载本轮客户端更新。此后「变阻器 开／关」直接生效，无需再刷新或重启服务。

- 开：使用原版铜线、瓷管、导轨、滑片结构的31帧控件。
- 关：恢复原生模型选择器，移除人物背景并恢复容器背景样式。
- 拖动：逐帧显示人物，松手才提交推理等级；键盘方向键与Home/End也可操作。
- 换模型：按精确模型ID选择人物系列。DeepSeek→梁文锋，GPT→奥特曼，Claude→达里奥。
- Fable、Opus共用达里奥31帧，但分别读取各自provider/model的推理能力；没有等级元数据时只预览图集，不发送虚构等级。

## 本次修正

旧开关只控制 `include:liang-calibrator`，新控件却是 `include:dsh-boss-slider`，导致开关显示“关”而新控件仍在。本轮统一了控制目标：

- 开启时只启用新31帧控件，并停用旧控件，避免两个占用模型座位。
- 关闭时关闭这两个控件，确保回到原生菜单。
- 点击前后回读后端；忙时锁定按钮防重复提交；失败恢复已改动状态并展示真实状态。
- 同页面、浏览器标签页及焦点切回时同步开关状态。

## 实现入口

- `src/core.cjs`：模型家族、31帧到真实推理等级的映射。
- `src/backdrop.cjs`：原版背景分层、计时及精确样式恢复。
- `src/client-body.js`：实体控件、模型选择、保存和回退。
- `build31.mjs`：从已核验素材与原版样式构建单文件客户端。
- `client.js`：实际部署的客户端产物，三套图集内嵌。
- `test31.cjs`：核心与背景回归测试。
- `../dsh-liang-toggle/client.js`：开关实现。
- `../dsh-liang-toggle/switch31.test.cjs`：开关回归测试。

维护命令（在本插件目录）：

```bash
node --test test31.cjs
node --test ../dsh-liang-toggle/switch31.test.cjs
node build31.mjs
node --check client.js
```
