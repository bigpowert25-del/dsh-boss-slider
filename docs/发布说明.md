## 市场索引怎么发布

`market/index.json` 里每个版本都钉一个 40 位 git commit（format 1 的 `source.type = "git"`），所以：

1. 先提交代码，拿到 commit SHA；
2. 把 SHA 写进 `market/index.json` 的 `versions[0].source.commit`；
3. 单独提交 market 文件并 push；
4. 市场里添加源地址（raw.githubusercontent 或 jsDelivr）。

改了代码就要重复 1–4，否则市场装的还是旧 commit。

## npm 之后可选

`npm publish` 能把 `source.type` 切成 `"npm"`，市场就不必钉 commit，用户安装也会走 registry 镜像。
本机当前没登录 npm，这一步留给用户授权后执行：`npm login && npm publish --access public`。
